# Staffly walkthrough images

These optimized WebP images show public marketing content and an explicitly synthetic demonstration workspace, not customer records.

| Asset | Capture | View |
| --- | --- | --- |
| `staffly-home.webp` | 2026-10-04 | Public landing page, 1280 × 720 |
| `staffly-workspace.webp` | 2026-10-05 | Demo overview, 1280 × 800 |
| `staffly-matly.webp` | 2026-10-05 | Matly assistant with synthetic prompts, 1440 × 1000 |

The public site at https://staffly-navy-psi.vercel.app/ disallows framing through both Content-Security-Policy and X-Frame-Options. The portfolio therefore provides a dated, labelled walkthrough and a link to the current site. These images are not presented as a live application. The older landing capture has a “Get early access” CTA; current entry uses “Get started / Try demo.”

When replacing a capture, review it for personal data, keep the synthetic-demo labels visible, update dimensions in `src/data/previews.ts`, and update its date here and the walkthrough caption.
